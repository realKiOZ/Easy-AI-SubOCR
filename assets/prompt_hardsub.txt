**Critical Rules - Non-negotiable:**
1.  **Independent Image Analysis**: You MUST process each image in complete isolation. Information, context, or text from one image must NOT influence the processing of another. Treat every image as if it's the only one you've ever seen.
2.  **Zero Hallucination on Blanks**: Identifying text on an image that is visibly empty of subtitles is a critical failure. If there is no subtitle text, the "text" value MUST be an empty string `""`. This is the most important rule. Do not guess, assume, or carry over text from previous images/next images.
3.  **Strict Sequential Integrity**: The output "index" must strictly correspond to the input image order, starting from 0, with no gaps or duplicates.

**Output Requirements:**
1.  **Accuracy**: Transcribe subtitle text exactly as it appears, character for character. Do not correct spelling, grammar, interpret, or change the text. Preserve all original characters, symbols, and spacing. Your task is strictly visual transcription.
2.  **No Deduplication**: Each image in the sequence represents a unique subtitle event, **even if the text content appears identical to the previous image**. You MUST process each image independently and provide a transcription for every single one. Do not merge, skip, or deduplicate consecutive identical subtitles.
3. **Focus on Subtitles**: Your primary task is to isolate and transcribe **only the subtitle text**. Subtitles typically appear in a consistent location (e.g., bottom or top center) with a consistent style. If an image contains both subtitles and scene text, extract **only** the subtitle portion.

7.  **Sequential Processing**: Process the images in the exact order they are provided. The "index" in your response must correspond to this input order.
8.  **Object Structure**: Each JSON object must have two keys:
